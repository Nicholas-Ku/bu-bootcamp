# BU CS Foundations Bootcamp

This is where I keep all my work for the Boston University Online AI Programs CS
Foundations Bootcamp. Starting with Module 4, every activity gets committed and
pushed here instead of being uploaded as a one-off screenshot, so this repo is the
permanent home for everything I build in the program.

## Structure
- **module1/**: Setting up the dev environment and my first Java programs
- **module2/**: Programming fundamentals like variables, control flow, methods, and file I/O
- **module3/**: Data structures and the object-oriented basics
- **module4/**: Notes on the Git and GitHub workflow

## Programs
Each module folder holds the actual Java source from that module's activity.
